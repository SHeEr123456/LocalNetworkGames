# 局域网游戏对战（中国象棋 / 坦克大战 / 飞行棋）

这是一个基于 **Node.js + WebSocket** 的局域网对战小项目：支持创建房间、加入房间、聊天与实时同步。

## 快速开始

1. 安装依赖

```bash
npm install
```

2. 启动服务器（默认端口 3000）

```bash
npm start
```

3. 打开页面

- **本机**：`http://localhost:3000`
- **局域网其他设备**：`http://你的电脑IP:3000`

## 目录结构（重构后）

```text
public/                 # 静态资源（浏览器端）
  index.html
  css/main.css
  js/
    main.js             # 浏览器入口
    online/OnlineGameApp.js
    games/
      chess/            # 中国象棋（客户端）
      tank/             # 坦克大战（客户端）
      flying/           # 飞行棋（客户端）

src/
  server/               # 服务端（Node.js）
    index.js            # 服务端入口（被根目录 server.js 引用）
    server.js           # HTTP 静态资源 + WebSocket 房间管理
    games/
      chess/            # 象棋（服务端权威逻辑）
      tank/             # 坦克（服务端 tick / 广播）
      flying/           # 飞行棋（服务端权威逻辑）
```

## 协议简述（WebSocket）

- **create_room**：创建房间（携带 `gameType` 和 `maxPlayers`）
- **join_room**：加入房间
- **get_rooms**：获取房间列表
- **chat**：聊天
- **move**：象棋走子（服务端校验与广播）
- **tank_input**：坦克输入（客户端周期发送，服务端 tick 后广播 `tank_state`）
- **flying_action**：飞行棋行动（`roll` 掷骰子 / `move` 移动棋子）
- **flying_state**：飞行棋状态同步（服务端广播完整游戏状态）
- **restart**：重开

## 游戏说明

### 中国象棋
- **服务端为权威状态**：象棋走子合法性与胜负判定都在服务端完成；客户端规则仅用于"高亮可走位置"的交互提示。
- **认输**：目前仅做了客户端本地提示（未实现服务端结算协议），如需联网结算可在服务端扩展消息类型。

### 坦克大战
- **实时对战**：WASD 移动，J 键射击
- **服务端 tick**：20 FPS 更新游戏状态并广播给所有玩家

### 飞行棋（经典规则）
- **2-4人对战**：每位玩家4架飞机，颜色：红、黄、蓝、绿
- **起飞规则**：掷出6点可起飞或移动已起飞的飞机，并获得额外回合
- **特殊规则**：
  - 连续三次掷出6点则本轮行动取消
  - 落点有敌方飞机则将其击落回基地
  - 落点有己方飞机则形成叠子（叠子受保护不会被击落）
  - 经过同色跳跃点可跳跃4格
  - 需要精确点数到达终点，超过则倒退
- **特殊格子**：
  - 🔵 大圆圈 = 起飞点（安全区，不会被击落）
  - 🔺 三角形 = 跳跃点（自动跳跃4格）
  - 终点通道 = 只有己方飞机可进入

## 使用说明

1. **启动服务器**：在一台电脑上运行 `npm start`
2. **创建房间**：房主选择游戏类型（象棋/坦克/飞行棋）和玩家数量，点击"创建新房间"
3. **加入房间**：其他玩家输入服务器地址，刷新房间列表并加入
4. **开始游戏**：
   - **象棋**：点击棋子查看可走位置，点击目标位置移动
   - **坦克**：WASD 移动，J 键射击
   - **飞行棋**：点击"掷骰子"按钮，然后点击高亮的棋子移动

**注意**：确保所有设备在同一局域网内，防火墙允许 3000 端口

## 技术特点

- ✅ **服务端权威**：所有游戏逻辑在服务端验证，防止作弊
- ✅ **实时同步**：WebSocket 实现低延迟的实时对战
- ✅ **多游戏支持**：统一的房间管理系统，支持多种游戏类型
- ✅ **状态机设计**：清晰的游戏阶段管理，易于扩展和维护
- ✅ **Canvas 渲染**：流畅的游戏画面和动画效果
